\# PantryChef



OPSC6312 Part 2 Android prototype.



\## Features

\- Register, login and password reset with Firebase Authentication

\- Settings saved to Cloud Firestore

\- Recipe search using TheMealDB REST API

\- Recipe detail and cooking mode

\- Unit tests

\- GitHub Actions CI



\## How to run

1\. Open the project in Android Studio

2\. Add google-services.json in the app folder

3\. Enable Email/Password in Firebase Authentication

4\. Create a Firestore database in test mode

5\. Run the app



\## API

TheMealDB: https://www.themealdb.com/api/json/v1/1/
